# Portal da Turma

Aplicação académica em React + TypeScript + Tailwind CSS para gerir estudantes e notas.

## Requisitos

- Node.js 18+

## Iniciar

```bash
npm install
npm run dev
```

Abre em **http://localhost:5173**

## Build

```bash
npm run build
```

## Páginas

| Rota | Página |
|------|--------|
| `/` | Início |
| `/estudantes` | Lista de estudantes |
| `/estudantes/:id` | Perfil do estudante |
| `/notas` | Gestão de notas |
| `/registo` | Registo de estudante |
| `/sobre` | Sobre o projeto |

## Tecnologias

- React 18 · TypeScript · Vite
- React Router v6
- Tailwind CSS v4
